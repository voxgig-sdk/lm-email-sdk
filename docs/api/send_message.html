application/json

Property Type Required Description
[].callback object No
[].callback.gateId string No The ID of the callback to be used. Can be set up in the Callbacks section of MyLINK portal. Mandatory when using mode "Gate" - not relevant to any other modes.
[].callback.mode enum: Profile, URL, Gate, None No Choose how you want to receive your Delivery reports. Mode Profile sends any DLRs towards your default configuration in MyLINK portal), URL sends towards a list of urls provided in the request, Gate sends towards a referenced configuration from MyLINK portal, or None (no DLR is sent anywhere). Each mode requires different request parameters, refer to the fields below.
[].callback.ttl integer (int32) No Time specified in milliseconds of how long the delivery report is supposed to live. Max value: 28800000. Default value: 14400000. Applicable to all callback modes except for "None". Example for mode Profile <pre><code>[ { "callback": { "mode": "Profile" } } ]</code></pre> Example for mode URL <pre><code>[ { "callback": { "mode": "URL", "urls": ["URL"], "ttl": 0 } } ]</code></pre> Example for mode Gate <pre><code>[ { "callback": { "mode": "Gate", "gateId": "fb8eac56-4311-4f09-94b9-54f4bee0acb6", "ttl": 0 } } ]</code></pre>
[].callback.urls array of string No List of URLs to receive DLRs on. Mandatory when using mode "URL" - not relevant to any other modes.
[].content object or object Yes Email message content.
[].expiration object No
[].expiration.absolute string (date-time) No Absolute time specified of when this message should expire. ISO8601 formatted string in UTC.
[].expiration.relative integer (int32) No Time specified in milliseconds of how long the message is supposed to live. The maximum value is 48 hours (172800000 milliseconds), which is also the default.
[].priority enum: Normal, High, Low No Set priority on your own messages. Priority only affects your own queue.
